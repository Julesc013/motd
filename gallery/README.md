# MOTD terminal gallery

The images show actual generated-script output captured in sized pseudo-terminals.
Observations are synthetic and configured hooks are disabled. Full-size images
retain every terminal row and column, including unused space and the prompt row.

| Collection | Purpose |
|---|---|
| [Showcase](showcase/README.md) · [interactive index](showcase/index.html) | 64 reproducible random selections, 16 at each requested size |
| [Individual settings](axes/README.md) · [interactive index](axes/index.html) | One setting at a time, with a declared comparison baseline |
| [Combined recipes](compositions/README.md) · [interactive index](compositions/index.html) | 12 compositions built from Classic's independent controls |
| [Compatibility](compatibility/README.md) | Interpreter, palette, colour and character-mode comparisons |
| [Design presets](designs/README.md) | Named configurations of the common presentation engine |
| [Gauges](bars/README.md) | Inline and wide usage bars |

Individual settings and combined recipes cover **80×25, 80×50, 120×50 and 160×50**.
The compatibility collections additionally retain 40-column cases. Each collection
contains its manifest, exact recipes, raw ANSI transcripts and lossless PNGs.

The showcase contact sheets are reduced navigation overviews. Follow their links
to inspect the unscaled source captures. No image generator is used for terminal
output.

See [the gallery guide](../docs/gallery.md) for regeneration and evidence checks.
